Простой Python-скрипт для автоматического извлечения **нескольких скриншотов из видео**, равномерно распределённых по всей длительности ролика.

Подходит для видео из **CapCut / Reels / Shorts / Instagram / YouTube** (в том числе H.265 / HEVC).

---

## Возможности

* Делает **N скриншотов**, равномерно разбросанных по видео
* Работает с видео **любой длины**
* Автоматически создаёт папку `screens` **рядом с видео**
* Поддерживает современные кодеки (через ffmpeg)
* Интерактивный ввод пути к файлу
* Кроссплатформенно (Windows / macOS / Linux)

---

## Требования

* Python **3.9+**
* Установленный **ffmpeg**

---

## Установка ffmpeg (Windows)

1. Скачайте ffmpeg:
   [https://www.gyan.dev/ffmpeg/builds/](https://www.gyan.dev/ffmpeg/builds/)

2. Распакуйте, например, в:

   ```
   C:\ffmpeg
   ```

3. Добавьте в **System PATH**:

   ```
   C:\ffmpeg\bin
   ```

4. Перезапустите терминал / IDE

5. Проверьте:

   ```bat
   ffmpeg -version
   ffprobe -version
   ```

Если версии отображаются — всё готово.

## Использование

Запустите скрипт:

```bash
python script.py
```

Далее:

1. Введите путь к видеофайлу
2. Укажите количество скриншотов (или нажмите Enter)

Результат:

```
video.mp4
screens/
 ├─ screen_01.jpg
 ├─ screen_02.jpg
 ├─ screen_03.jpg
 ├─ ...
```

---

## Как выбираются кадры

Скриншоты берутся **равномерно по всей длительности видео**, а не подряд, что позволяет получить репрезентативные кадры всего ролика.
