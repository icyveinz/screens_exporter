Простой Python-скрипт для автоматического извлечения **нескольких скриншотов из видео**, равномерно распределённых по всей длительности ролика.

Скрипт принимает **папку с видео**, рекурсивно находит все видеоролики внутри и создаёт скриншоты для каждого файла.

Подходит для видео из **CapCut / Reels / Shorts / Instagram / YouTube**
(в том числе H.265 / HEVC).

---

## ✨ Возможности

* Рекурсивно обрабатывает **все видеофайлы в папке**
* Делает **N скриншотов** для каждого видео
* Скриншоты **равномерно распределены по всей длительности ролика**
* Работает с видео **любой длины**
* Для каждого видео автоматически создаёт папку `screens` **рядом с файлом**
* Поддерживает современные кодеки (через ffmpeg)
* Интерактивный ввод пути к папке
* Кроссплатформенно (Windows / macOS / Linux)

---

## 📦 Требования

* Python **3.9+**
* Установленный **ffmpeg**

---

## 🔧 Установка ffmpeg (Windows)

1. Скачайте ffmpeg:
   [https://www.gyan.dev/ffmpeg/builds/](https://www.gyan.dev/ffmpeg/builds/)

2. Распакуйте, например, в:

   ```
   C:\ffmpeg
   ```

3. Добавьте в **System PATH**:

   ```
   C:\ffmpeg\bin
   ```

4. Перезапустите терминал / IDE

5. Проверьте установку:

   ```bat
   ffmpeg -version
   ffprobe -version
   ```

Если версии отображаются — всё готово.

## 🚀 Использование

Запустите скрипт:

```bash
python script.py
```

Далее:

1. Введите путь к папке с видео
2. Укажите количество скриншотов для каждого ролика
   (или нажмите Enter — будет использовано значение по умолчанию)

## 📂 Пример результата

Исходная структура:

```
videos/
 ├─ video1.mp4
 ├─ folder/
 │   └─ video2.mp4
```

После выполнения:

```
videos/
 ├─ video1.mp4
 ├─ screens/
 │   ├─ screen_01.jpg
 │   ├─ screen_02.jpg
 │   └─ ...
 ├─ folder/
 │   ├─ video2.mp4
 │   └─ screens/
 │       ├─ screen_01.jpg
 │       └─ ...
```

---

## 🧠 Как выбираются кадры

Скриншоты берутся **равномерно по всей длительности видео**, а не подряд.
Это позволяет получить репрезентативные кадры всего ролика, а не одного фрагмента.
